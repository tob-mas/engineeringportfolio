# 🏎️ 3D Model – 2025 Formula 1 Concept Car

This project presents a **fully detailed 3D CAD model of a 2025-generation Formula 1 concept car**, developed in **SolidWorks 2020**.

The model was created as part of a wider **aerodynamic development study**, where the geometry was later analysed and refined using CFD. Rather than being a purely visual model, this CAD assembly was designed to support **simulation-led optimisation**, reflecting real motorsport engineering workflows.

---

## 🧠 Engineering Context

The car was developed using a **ground-effect dominated aerodynamic philosophy**, representative of Formula 1 cars in the 2022–2025 regulation era.

The CAD model includes all major aerodynamic systems:
- Front wing and endplates  
- Sidepods and inlet geometry  
- Floor and diffuser region  
- Rear wing assembly  
- Brake ducts and secondary flow features  

The geometry was intentionally built to allow **CFD analysis and iterative refinement**, forming the basis for a structured development process:
> *Design → Analyse → Identify issues → Optimise → Re-evaluate*

## 🛠️ CAD Development Approach

- Full vehicle model created using **surface and solid-body modelling** techniques [1](https://eaton-my.sharepoint.com/personal/tobyimason_eaton_com/Documents/zRandom/Microsoft%20Copilot%20Chat%20Files/Portfolio%20Project%20Report.pdf)  
- Focus on **complete system integration**, not just isolated components [1](https://eaton-my.sharepoint.com/personal/tobyimason_eaton_com/Documents/zRandom/Microsoft%20Copilot%20Chat%20Files/Portfolio%20Project%20Report.pdf)  
- Geometry designed to be **CFD-ready**, enabling aerodynamic evaluation  
- Key areas modelled with aerodynamic intent:
  - Smooth surface transitions to reduce flow separation  
  - Controlled inlet shaping for sidepods and ducts  
  - Floor geometry suited for underbody airflow development

## 📊 Why This Model Matters

This model is not just a visual representation — it forms the foundation of a **simulation-led aerodynamic development process**.

The CAD was later used to:
- Identify areas of **flow detachment and poor pressure behaviour**  
- Implement **targeted geometry changes across multiple components**  
- Support **iterative design optimisation using CFD**  

This demonstrates:
✅ Ability to build complex engineering CAD
