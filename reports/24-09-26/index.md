## 📊 Project Overview

This project presents a structured aerodynamic study of a NACA 6412 aerofoil, including:

- Aerofoil geometry development in CATIA V5
- Mathematical verification of the NACA 6412 profile
- CFD domain and mesh development
- Mesh sensitivity assessment
- Aerodynamic analysis across multiple angles of attack
- Lift, drag, and aerodynamic efficiency evaluation
- Drag polar analysis
- CFD result validation and comparison
